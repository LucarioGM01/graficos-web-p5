Sección Informativa

1. La etiqueta HTML <canvas> y contextos 2D

La etiqueta <canvas> de HTML5 proporciona un área en la página donde se pueden dibujar gráficos de forma dinámica mediante JavaScript. Por sí sola, la etiqueta es solo un contenedor transparente. Para dibujar en ella, se utiliza una API de renderizado solicitando un "contexto". El contexto "2d" permite trazar formas primitivas, líneas, colores, texto e imágenes mediante un sistema de coordenadas (x, y) donde el origen (0,0) está en la esquina superior izquierda.

2. Fundamentos de la librería p5.js

p5.js es una librería de JavaScript diseñada para hacer que la programación visual sea accesible. Abstrae la complejidad del contexto 2D del canvas tradicional. Sus fundamentos se basan en dos funciones principales:

• setup(): Se ejecuta una sola vez al iniciar el programa. Se usa para configurar el lienzo (ej. createCanvas()) y definir variables iniciales.
• draw(): Se ejecuta en un bucle continuo (por defecto a 60 FPS), actualizando las posiciones y redibujando el fondo, lo que permite crear animaciones cuadro por cuadro.
