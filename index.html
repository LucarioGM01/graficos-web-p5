Sección Informativa

1. La etiqueta HTML <canvas> y contextos 2D

La etiqueta <canvas> de HTML5 proporciona un área en la página donde se pueden dibujar gráficos de forma dinámica mediante JavaScript. El contexto "2d" permite trazar formas primitivas, líneas, colores, texto e imágenes mediante un sistema de coordenadas (x, y) donde el origen (0,0) está en la esquina superior izquierda.

2. Fundamentos de la librería p5.js

p5.js es una librería de JavaScript que abstrae la complejidad del contexto 2D del canvas tradicional. Sus fundamentos se basan en dos funciones:
• setup(): Se ejecuta una sola vez al iniciar. Configura el lienzo y valores iniciales.
• draw(): Se ejecuta en un bucle continuo (60 FPS), actualizando las posiciones y redibujando el fondo para crear animaciones.
